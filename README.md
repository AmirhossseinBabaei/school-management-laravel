# 🏫 School Management System (Laravel)

**School Management System** یک پروژه‌ی جامع و ماژولار برای مدیریت مدرسه است که با فریم‌ورک قدرتمند **Laravel** توسعه داده شده است.  
این سیستم امکان مدیریت دانش‌آموزان، معلمان، کلاس‌ها، نمرات، حضور و غیاب، و گزارش‌ها را به روشی تمیز، امن و قابل توسعه فراهم می‌کند.

---

## ✨ ویژگی‌های کلیدی

- 🔐 مدیریت کاربران (ادمین، معلم، والدین، دانش‌آموز)
- 🏷️ مدیریت کلاس‌ها، دروس، و برنامه زمانی
- 📊 ثبت و مشاهده نمرات
- 📅 حضور و غیاب (دستی یا QR)
- 📈 گزارش‌گیری پیشرفته (PDF / CSV)
- 📨 سیستم اطلاع‌رسانی از طریق ایمیل و اعلان
- 🧩 معماری تمیز با Service & Repository Pattern
- 🧪 تست‌های واحد و انتهابه‌انتها (PHPUnit / Pest)
- ⚙️ RESTful API با احراز هویت Laravel Sanctum
